항공권 예약에 쓰는 할인코드

항공권 결제 화면에서만 적용되는 코드입니다. 호텔 결제창에 넣으면 인식되지 않으니 주의하세요.

호텔 예약에 쓰는 할인코드

할인코드 적용 방법과 주의할 점

코드를 입력하는 위치는 항공권과 호텔 모두 비슷합니다. 예약할 상품과 날짜를 먼저 선택하고, 결제 정보를 입력하는 마지막 단계로 넘어가면 쿠폰 코드 또는 프로모션 코드를 입력하는 칸이 따로 있습니다. 여기에 코드를 넣고 적용 버튼을 누르면 총 결제 금액에서 할인 금액이 바로 반영되는지 확인할 수 있습니다.
